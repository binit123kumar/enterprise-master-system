# 🛡️ EnterpriseOS — Binit's Master System

Enterprise-Grade AI Agent Dashboard with full deployment control.

## 🚀 Tech Stack
- **Frontend**: React.js + Vite
- **Backend**: ASP.NET Core Web API
- **AI Agent**: Python + FastAPI
- **Database**: SQL Server
- **Deploy**: Render.com / Azure

## 📁 Page Structure
| File | Purpose |
|------|---------|
| AgentDashboard.jsx | Main control center |
| ProjectManager.jsx | Project list & management |
| CodeWorkspace.jsx | Code editor & file browser |
| GitControlPanel.jsx | Git status, commit, push |
| DeploymentCenter.jsx | Deploy, rollback, history |
| VoiceCommandCenter.jsx | Voice input & processing |
| SecurityVault.jsx | Auth, PIN, fingerprint |
| SystemPromptLibrary.jsx | Prompt management |
| LiveMonitoring.jsx | Logs, health, alerts |
| SystemSettings.jsx | Config & preferences |

## ⚡ Quick Start
```bash
npm install
npm run dev
```

## 🚀 Deploy on Render
1. Push to GitHub
2. New Static Site on Render
3. Build: `npm run build`
4. Publish: `dist`

## 🔐 Security
All deployments require: Voice + PIN + Fingerprint
