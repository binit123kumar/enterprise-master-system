## **Troubleshooting**

### **SSH Connection नहीं हो रहा?**

```bash
# 1. IP correct है check करो
ping 132.145.123.456

# 2. SSH key path correct है?
ls -la ~/.ssh/enterprise-os-vm.key

# 3. Permission check करो
chmod 600 ~/.ssh/enterprise-os-vm.key

# 4. Firewall check करो (Oracle console में)
Networking → Security Lists
→ Add rule for SSH (port 22)
```

### **Instance नहीं बन रहा?**

```
Possible reasons:
1. Free tier limit exceed (2 instances already)
   → Delete old instances
   
2. Region में resources available नहीं
   → Different region try करो
   
3. Always Free Eligible नहीं selected
   → Shape फिर से check करो

Contact: Oracle Support (free tier eligible)
```
